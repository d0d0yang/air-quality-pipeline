Air Quality Pipeline

A daily Azure Data Factory pipeline that pulls hourly pollution and weather data for Southern Ontario into Azure SQL, cleans and links it with Python and T-SQL, and forecasts tomorrow's PM2.5 at every monitoring station on a public map.
